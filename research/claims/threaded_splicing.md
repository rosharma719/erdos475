# Threaded splicing for IRC (GPT 2026-11-22; AUDITED IN-SESSION by Claude, own implementation)
**Pitfall found by GPT:** inserting a closed zero-sum component at a vertex repeats a vertex; the repair is to thread a distinguished +M step of the core THROUGH each minimal zero-sum component (replace M by r_1..r_j, M, r_{j+1}..r_n where r is the component's negative-rooted cycle and q_j is its minimum -h).
**Lemma 1.1:** a minimal zero-sum signed component has a simple cycle of range h ≤ min(U+D−1, W) (W = sum of its positive steps). **Lemma 2.1 (two vacant rails):** if H=Σh_i < M and [x−H,x−1], [x+M−H,x+M−1] contain no vertex of the core cycle C (distinguished step x→x+M), the threaded cycle is simple, range grows by H. **Thm 3.1:** P,N sets, symmetric core S ⊆ P∩N with M=max S, b=second largest (0 if |S|=1), remainder partitioned into minimal components; if b+H ≤ M−1, IRC holds with range exactly M+b+H ≤ 2M−1 ≤ maxP+maxN−1. **Cor 3.2:** Σ(P∖S) ≤ M−b−1 suffices. **Thm 4.1:** core (+x,+y,−(x+y)) with remainder positive weight < x gives IRC even with P∩N=∅.
**Claude audit (experiments/audits/threaded_splice_independent.py, written from the proofs):** 5,303 random (P,N) with symmetric core + arbitrary balanced remainder and b+H≤M−1: multiset exact, vertices distinct, range = M+b+H ≤ maxP+maxN−1, and Lemma 1.1's bound h ≤ min(U+D−1,W) held for every component; 5,103 of them satisfied the Cor 3.2 test (and Thm 3.1 held in all); 4,000 random asymmetric 3-step-core instances (Thm 4.1): valid with range x+y+H ≤ maxP+maxN−1; GPT's example P={50,7,1,5}, N={57,2,4} gives a valid walk (my sign rule picks a different component order: range 63 vs GPT's 62). Hand proof of the threading lemma re-derived (new vertices x+q_i (i≤j) and x+M+q_i (i≥j), q_i∈[−h,−1] distinct; rails vacant; later components land strictly below earlier ones).
**Scope warning (Claude):** the hypotheses b+H ≤ M−1 (remainder positive weight smaller than the core's top magnitude) describe a THIN family: a set dilated to small representatives with k elements of size ~p/2 has remainder weight ~k·p/4 ≫ M. This extends the symmetric result to 'symmetric core + light remainder', not to generic sets. GAP-S1..S3 (GPT) remain: no interleaving for components heavier than the rails.
