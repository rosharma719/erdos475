# Symmetric IRC / Graham for every symmetric set (GPT 2026-11-22; AUDITED IN-SESSION by Claude, own implementation)

**Theorem.** S={b_1>b_2>...>b_m>0}, M=b_1. With δ=(b_2,−b_3,b_4,…) (descending, alternating signs), the ordering W=(δ_1..δ_{m−1}, M, −δ_{m−1},…,−δ_1, −M) of the 2m integers ±b_i has distinct partial sums (vertices {T_0..T_{m−1}} ∪ {M+T_0..M+T_{m−1}}), T_j the prefix sums of δ, all in [0,b_2]; range = M+b_2 ≤ 2M−1 (m=1: range M). Hence IRC holds for P=N=S, and for every prime p and every symmetric A=−A ⊆ F_p^× (range ≤ 2M−1 ≤ p−2) A has an explicit valid cyclic ordering, for all sizes.
**Lemma used** (descending alternating path): even-indexed prefix sums increase from 0, odd-indexed decrease from d_1, and the smallest odd exceeds the largest even; so all lie in [0,d_1] and are distinct.
**Complementary theorem (minimal zero-sum IRC).** If P∪(−N) has no proper nonempty zero-sum subcollection, the sign rule (take a negative step when the sum is positive, a positive step when negative) gives distinct partial sums in [1−D,U], range ≤ U+D−1.
**Claude audit (experiments/audits/symmetric_irc_independent.py):** hand proof re-derived; (1) all 65,535 nonempty S ⊆ [1..16] verified (multiset, closure, distinct vertices, range=b_1+b_2); (2) every symmetric subset of F_p^× for ALL primes p ≤ 31, including the full group: 52,068 sets, 0 invalid mod p; (3) 20,000 random symmetric sets, primes 41..997: 0 invalid; (4) 3,142 minimal zero-sum signed pairs with values ≤ 12: sign-rule walk valid, range ≤ maxP+maxN−1, 0 failures.
**Consequences.** (i) FOLD (Claude, half-cycle form) is superseded: valid cycles for all symmetric sets are now PROVED by a different, simpler construction (the half-cycle form existence stays data-only). (ii) The 'dense symmetric' family on which the zigzag conjecture failed is solved for every prime; any A whose complement is symmetric is symmetric. (iii) The walk is a Walecki-type rotational sequencing generalised to arbitrary subsets: cycle invariant under the reflection x↦M−x.
**Open (GAP-S2):** joining minimal zero-sum atoms of an arbitrary balanced collection within one cycle and the bound maxP+maxN−1; equivalently IRC for P≠N. Symmetric sets are a thin family (2^((p−1)/2) of 2^(p−1) sets); a typical set of density d has only about d²p/2 inverse pairs.
