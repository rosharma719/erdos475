# Contractions of symmetric walks (Claude exploration, 2026-11-22; DATA ONLY, no proof)

**Question.** Given the proved symmetric walk W_S (steps ±S, vertex set V_S = T ∪ (T+M)), which zero-sum sets A (up to dilation) are the step-label sets of a vertex-deletion (contraction) of W_S for SOME S ⊆ [1..(p−1)/2]? A contraction of a valid cycle is a valid cycle (labels distinct, nonzero, vertices a subset), so every covered A has a valid cycle, with an explicit certificate (S, kept vertices, dilation).
**Exhaustive coverage of zero-sum orbits (|A| from 4 up to p−6):** p=13: 24/24; p=17: 244/244; p=19: 781/784 (99.6%); p=23: 8,283/8,358 (99.1%). By size at p=23: 100% for every |A| ≤ 11 = (p−1)/2; |A|=12: 99.4%, 13: 99.0%, 14: 95.7%, 15: 95.5%, 16: 91.6%, 17: 98.1%. At p=19: 100% except one orbit each at |A|=9 ({1,4,5,6,7,9,11,16,17}), 12, 13. All uncovered orbits are dense (≥ p/2). Only ONE walk per S (the Walecki-type one) is used; other cycles on ±S are not tried.
**Structure.** Minimal |S| needed is about |A|/2 + 1 (p=17 averages 2.6 for |A|=4 up to 6.6 for |A|=12); the number of deleted vertices is ≤ 4 at p=17 (≤ 3 at p=13) — but this is a small-p artefact: a set with no inverse pairs can keep at most one of each ±b_i as a single-step label, so at large p most steps must be absorbed in multi-step blocks (Θ(|A|) deletions).
**Counting.** Σ_S 4^{|S|} = 5^r raw (S, deletion) patterns versus ≈ 4^r/p orbits: no counting obstruction to full coverage, but nothing forces it either.
**p=29 sampled (|S|≤9 cap, 300 random zero-sum sets per size; cap makes sizes ≥19 impossible):** |A|=6..11: 300/300 each (100%); 12: 299/300; 13: 289/300; 14: 242/300 (cap-limited); 15..18 decay to 0 only because 2|S|≤18.
**Status.** Neither a conjecture with a proof route nor a refutation; sampled coverage at p=29 is running. Possible conjecture SYMWALK≤: every zero-sum A with |A| ≤ (p−1)/2 is such a contraction. If true and provable it would give Graham for all sizes ≤ p/2 with an explicit construction. Scripts: experiments/exploration/sym_contraction*.cpp, sym_contraction_explain.py.

**Restriction S ⊆ classes(λA) is too strong (Claude).** Sampled with S restricted to the classes of λA and a 200k-node DFS cap: p=31 |A|=10 30/30, |A|=14 28/30; p=37 |A|=10 29/30, |A|=14 29/30, |A|=17 19/30; p=41 |A|=12 30/30, 16: 21/30, 19: 17/30; p=47 |A|=14 27/30, 18: 17/30. The p=37 miss A={23,26,7,3,17,34,21,11,35,8} IS representable with unrestricted S: dilation 2, S={17,16,15,14,11,7,6,5,2}, kept vertices idx 0,1,2,3,5,6,7,9,11,12 of the 18-step walk. The misses above are therefore artefacts of the restriction (and possibly of the node cap), not counterexamples. Unrestricted-S sampling results are in experiments/exploration/sym_scale_u.out.

**Heuristic count (Claude; random-label model, NOT a proof).** Number of (S,K) patterns with |S|=m, |K|=k is C(r,m)·C(2m,k); a pattern yields k distinct labels with probability ≈ ∏(1−i/(p−1)); zero-sum k-sets number ≈ C(p−1,k)/p; expected hits per orbit (all dilations) E(p,k). log10 E: p=29: k=0.3p: 4.6, 0.45p: 2.7; p=59: 6.9 / 3.4; p=127: 11.0 / 3.7; p=211: 16.1 / 4.1 (0.5p: −0.6); p=401: 27.0 / 3.7 (0.5p: −5.0). So in the random model every zero-sum set of size ≤ ~0.45p has 10^3–10^47 representations for all p up to 401, and coverage can only fail near |A|≈p/2 for very large p. Expect the true statement to be 'all |A| ≤ cp' for some c<1/2 (or ≤ p/2 for small p). A proof would need equidistribution of the label sets of the explicit family (Fourier/second-moment) or a constructive greedy/matching argument; the margin is enormous, so crude estimates might suffice, but explicit large-p constants are the usual obstacle.

## Larger-prime sampled results (Claude; random-S sampling with a bounded search budget, 30 random zero-sum sets per cell — NEGATIVE cells are search-limited, not refutations)
Spiral walks, S unrestricted (4000 random S per dilation, DFS cap 200k nodes): p=37 |A|=10: 30/30, 14: 30/30, 17 (0.46p): 21/30; p=41 |A|=12: 30/30, 16 (0.39p): 28/30; p=47 |A|=14 (0.30p): 30/30.
Generalised (random order/sign) walks, random S, 4000 walks per dilation: p=37 |A|=10: 30/30, 17: 13/30, 22: 0/30, 26: 1/30; p=41 |A|=12: 30/30, 19: 4/30, 24: 0/30. Random generalised walks are LESS effective than the structured spiral at equal budget; coverage near and above p/2 is not certifiable by sampling.
Summary: GSW/spiral contraction coverage is ≈100% for |A| ≲ 0.35–0.4p at p=29..47, degrades toward p/2 under limited search; dense sets (> p/2) were covered only in the exhaustive p ≤ 23 runs. Consequence for the plan: GSW is a backup route for sizes up to ~0.4p; the dense side needs a different mechanism, whereas Asymmetric Zigzag is a single statement covering all sizes (research/PLAN.md updated accordingly).
